Sobre o Projeto

Este site foi desenvolvido como projeto final de férias para demonstrar conhecimentos práticos em desenvolvimento Front-End responsivo.

Utilizamos uma combinação de HTML5 semântico, estilização personalizada em CSS3, o framework Bootstrap para estrutura responsiva rápida e scripts em JavaScript para dinamismo e interatividade com o usuário.
